## Topic

YachtRent is a yacht charter company website. Visitors can browse the fleet, compare yachts, explore sea destinations and send a booking request.

## Pages

| Page | Description |
|---|---|
| `index.html` | Home: hero section with call-to-action and key advantages |
| `yachts.html` | Yacht catalog (cards) and comparison table |
| `destinations.html` | Popular routes with starting prices |
| `about.html` | Company information and statistics |
| `contact.html` | Booking form and contact details |

## Features

- 5 pages connected by a navigation bar on every page (the current page is highlighted)
- Semantic HTML5: `header`, `nav`, `main`, `section`, `article`, `footer`
- Table: yacht comparison (`yachts.html`)
- Form: booking request with HTML5 validation (`required`, `email`, `tel`, `date`, `select`) (`contact.html`)
- CSS: Flexbox (statistics block, contact list), Grid (destinations), positioning (`relative` / `absolute` price badges)
- IDs and classes used for styling and structure
- Responsive design: Bootstrap grid and utility classes, media queries for tablet (992px) and mobile (576px)
- No custom JavaScript (Bootstrap bundle is used only for the mobile menu)
